# 계약서 기록 관리 (Contract Record Manager)

계약을 직접 기록하고 상태·만료일·금액을 한눈에 관리하는 모바일 우선 PWA 앱입니다.
(골프 학습 기록 앱처럼, 항목을 하나씩 쌓아 관리하는 기록형 앱)

## 주요 기능

- **계약 등록/수정/삭제** — 계약명, 거래처, 담당자, 유형, 상태, 금액, 체결일, 만료일, 메모
- **대시보드 통계** — 전체 건수, 진행중, 총 계약금액(해지 제외), 만료 임박(30일), 완료
- **상태 필터 + 검색** — 진행중/완료/보류/해지 필터, 계약명·거래처·담당자 검색
- **만료 D-day 표시** — 만료 임박 계약을 색상으로 강조하고 목록 상단에 우선 정렬
- **엑셀 내보내기** — 전체 계약 목록을 `.xlsx` 파일로 저장
- **오프라인 저장** — 데이터는 브라우저 `localStorage`에 저장되어 오프라인에서도 동작
- **PWA 설치** — 홈 화면에 추가하면 네이티브 앱처럼 전체화면 실행

## 사용 방법

1. 브라우저에서 `index.html` 열기 (또는 정적 호스팅에 배포)
2. 오른쪽 아래 **+** 버튼으로 계약 기록 추가
3. **✨ 예시 데이터** 버튼으로 샘플을 넣어 화면을 미리 확인 가능
4. Chrome 메뉴(⋮) → **"홈 화면에 추가"** 로 앱 설치

## 기술

- 순수 HTML / CSS / JavaScript (프레임워크 없음, 단일 파일)
- 데이터 저장: `localStorage`
- 엑셀 내보내기: SheetJS (xlsx)
- PWA: `manifest.json` + Service Worker(`sw.js`)로 오프라인 캐시

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 앱 전체 (UI + 로직) |
| `manifest.json` | PWA 매니페스트 |
| `sw.js` | 서비스 워커 (오프라인 캐시) |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |
