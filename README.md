# ⛳ 골프 공부 노트 (Golf Study Journal)

골프 공부한 내용을 기록하고 다시 꺼내보며 실력을 쌓는 학습 노트 PWA 앱입니다.
설치 없이 브라우저에서 바로 쓰고, 홈 화면에 앱으로 설치하면 오프라인에서도 동작합니다.

## 주요 기능

- **카테고리별 기록** — 드라이버 / 아이언 / 웨지·숏게임 / 퍼팅 / 스윙·자세 / 멘탈·루틴 / 코스공략 / 규칙·에티켓 / 체력·장비 / 기타
- **노트 작성** — 날짜, 제목, 배운 내용, 태그를 자유롭게 기록
- **검색 & 필터** — 제목·내용·태그 키워드 검색, 카테고리 탭 필터
- **학습 통계** — 전체 노트 수, 이번 달 기록 수, 연속 기록일(스트릭)
- **오프라인 저장** — 모든 데이터는 브라우저(localStorage)에 저장, 서버 전송 없음
- **백업/복원** — JSON 파일로 내보내기·가져오기 (기기 이동 시 안전하게 이동)
- **PWA** — 홈 화면에 설치하면 전체화면 네이티브 앱처럼 사용

## 사용 방법

1. `index.html`을 브라우저에서 열거나 정적 호스팅(GitHub Pages 등)에 배포합니다.
2. 오른쪽 아래 **+** 버튼으로 새 노트를 추가합니다.
3. 노트 카드의 **⋯** 메뉴에서 수정·삭제할 수 있습니다.
4. 하단 **백업 내보내기**로 데이터를 파일로 저장하고, 다른 기기에서 **가져오기**로 복원합니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 앱 전체 (UI · 로직 · 스타일 단일 파일) |
| `manifest.json` | PWA 매니페스트 |
| `sw.js` | 서비스 워커 (오프라인 캐싱) |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |

## 데이터 보관 안내

- 노트는 사용 중인 브라우저에만 저장됩니다. 브라우저 데이터를 지우면 노트도 삭제되니, 주기적으로 **백업 내보내기**를 권장합니다.
- 별도의 서버나 계정이 필요 없고, 어떤 데이터도 외부로 전송되지 않습니다.
