# sales-app

## 📊 매출 합산 앱 (`/index.html`)
사진(메모·영수증·장부)을 올리면 AI가 월별 매출을 자동 집계하는 PWA.

## 🧳 가족 여행 플래너 (`/trip/index.html`)
가족 여행 일정과 경비를 함께 기록하고 자동 정산하는 PWA.

- **일정**: 날짜별(Day 1, Day 2 …) 타임라인으로 일정 관리
- **경비**: 누가 결제했는지, 누구와 나눌지(N분의 1) 기록 · 카테고리별 지출 요약
- **정산**: 멤버별 낸 돈/부담 몫 자동 계산 + 최소 송금 조합 제시 + 카톡 공유
- **공유**: 여행 데이터를 JSON 파일로 내보내기/가져오기 → 가족 모두 같은 내용 보기
- 서버 없이 동작 (localStorage 저장), 홈 화면에 앱으로 설치 가능
