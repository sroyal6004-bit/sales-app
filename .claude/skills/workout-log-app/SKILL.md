# 운동일지 앱 (Workout Log)

**먼저 `personal-pwa-app` 스킬을 읽고 그 공통 규칙을 모두 적용한다.** 단일 HTML PWA,
오프라인 우선, 다크/한국어/모바일, 뒤로가기 홈 제어, 연결 코드 기반 Firebase 동기화,
PWA 자동 업데이트, JSON 백업, Playwright 스모크 테스트 후 커밋 — 이 인프라는 그대로
가져오고, 아래는 운동일지에 특화된 부분만 정의한다.

## 데이터 모델

하루의 운동을 **세션(session)** 단위로 기록. 한 세션에 여러 종목, 각 종목에 여러 세트.
localStorage + Firestore(`spaces/{코드}` 문서의 `sessions` 필드)에 저장, 병합은 공통 규칙 동일.

```js
session = {
  id, date,                 // 'YYYY-MM-DD'
  parts: [부위 id, ...],    // 이 세션에서 운동한 부위(태그)
  duration,                 // 분(선택)
  memo,                     // 선택
  exercises: [
    { name: '벤치프레스', sets: [ { weight: 60, reps: 10 }, { weight: 60, reps: 8 } ] },
    ...
  ],
  created, updated, deleted
}
```

체중 기록은 별도의 가벼운 배열로 두면 추이 그래프에 쓰기 좋다:
`weights = [{ id, date, kg, updated, deleted }]` (선택 기능).

## 부위/종류 카테고리

```js
PARTS = [가슴💪, 등🔙, 하체🦵, 어깨🎯, 팔💪, 코어🧱, 유산소🏃, 전신🔥]
```

부위는 세션 태그 + 필터로 사용. 종목 이름은 자유 입력하되 **최근 사용 종목을 자동완성/추천**
하면 입력이 훨씬 빨라진다(자주 하는 운동이 반복되므로).

## 화면 구성 (상단 2탭)

- **🏋️ 기록**: 세션 리스트(최신순). 각 세션 카드: 날짜·부위 칩·총 볼륨·종목 수 요약,
  펼치면 종목별 세트(60kg×10, 60kg×8 …). 부위 칩 필터로 걸러보기.
- **📈 통계**: 이번 주 요약 + 차트.
  - **주간 운동 빈도** 막대 그래프(최근 8~12주).
  - **종목별 중량 추이**: 종목을 하나 고르면 그 종목의 세션별 최고 중량(또는 추정 1RM
    = weight × (1 + reps/30))을 SVG 라인 차트로. (골프 스코어 라인 차트 패턴 재사용, 단
    운동은 **높을수록 좋음**이라 y축 방향만 반대로.)
  - (체중 기록 쓰면) **체중 추이** 라인 차트.

FAB(+) → 세션 추가 모달: **날짜 → 부위 선택 → 종목 추가(이름) → 각 종목에 세트 추가
(중량·횟수, +세트 버튼) → 메모**. 세트는 직전 세트 값을 기본값으로 복제하면 입력이 빠르다.

## 통계 (요약 카드)

- 이번 주 **운동 횟수(세션 수)**, **연속 기록일(스트릭)**(공통 규칙의 스트릭 로직 재사용),
  이번 주 **총 볼륨**(Σ 중량×횟수).
- 종목별 **개인 최고 기록(PR)** 하이라이트(예: 벤치 최고 70kg).

## 도메인 UX 포인트

- **볼륨 계산**: 세트별 `weight × reps` 합계가 운동량 지표. 세션·주·종목 단위로 집계.
- **빠른 반복 입력**: 최근 종목·직전 세트값 복제·부위 프리셋(루틴)으로 손 덜 가게. 운동 중
  한 손으로 쓰는 상황이라 **큰 +버튼과 숫자 스테퍼**가 중요. 숫자 입력은 `inputmode="numeric"`.
- **성장 시각화가 동기부여**의 핵심 — 중량/볼륨이 우상향하는 걸 보여주는 데 집중.
- **유산소 세션**은 세트/중량 대신 시간·거리 위주로 유연하게(세트 배열 비우고 duration·memo 사용).
- 내보내기: JSON 백업(공통). 필요 시 CSV(날짜·종목·세트·중량·횟수).

## 적용 체크리스트

- [ ] personal-pwa-app 공통 규칙 전체 적용
- [ ] 세션 = 부위 태그 + 종목[세트{중량,횟수}] 모델
- [ ] 기록 탭(세션 카드, 부위 필터) + 세트 빠른 입력(직전값 복제)
- [ ] 이번 주 횟수·스트릭·총 볼륨 요약, 종목별 PR
- [ ] 주간 빈도 막대 + 종목별 중량 추이(SVG, 높을수록 좋음) + (선택) 체중 추이
- [ ] 최근 종목 자동추천, 큰 +버튼/숫자 스테퍼
- [ ] JSON 백업 + 연결 코드 동기화(sessions 병합, 툼스톤) + Playwright 테스트 후 커밋
