# 가계부 앱 (Expense Tracker)

**먼저 `personal-pwa-app` 스킬을 읽고 그 공통 규칙을 모두 적용한다.** 단일 HTML PWA,
오프라인 우선, 다크/한국어/모바일, 뒤로가기 홈 제어, 연결 코드 기반 Firebase 동기화,
PWA 자동 업데이트, JSON 백업, Playwright 스모크 테스트 후 커밋 — 이 인프라는 그대로
가져오고, 아래는 가계부에 특화된 부분만 정의한다.

## 데이터 모델

거래(transaction) 배열을 localStorage + Firestore(`spaces/{코드}` 문서의 `txns` 필드)에 저장.
동기화 병합은 공통 규칙과 동일(id + updated 최신 우선, 삭제는 `deleted:true` 툼스톤).

```js
tx = {
  id, kind: 'expense' | 'income', amount: Number,  // 원 단위 정수
  cat,            // 카테고리 id
  date,           // 'YYYY-MM-DD'
  memo,           // 선택
  created, updated, deleted
}
```

예산은 월 단위 하나만 두면 충분: `budget = { 'YYYY-MM': amount }` (선택 기능).

## 카테고리 (지출/수입 분리)

```js
EXPENSE = [식비🍚, 카페·간식☕, 교통🚌, 생활·마트🛒, 쇼핑🛍️, 주거·통신🏠,
           의료·건강💊, 문화·여가🎬, 교육📚, 경조사🎁, 기타💸]
INCOME  = [급여💰, 용돈🧧, 부수입💼, 금융소득📈, 기타➕]
```

카테고리는 이모지 + 라벨. 지출/수입 토글에 따라 선택지가 바뀐다.

## 화면 구성 (상단 2탭)

- **📒 거래내역**: 상단에 `‹ 2026.07 ›` **월 이동 네비게이션**. 그 아래 이번 달 요약
  (수입/지출/잔액 3칸). 아래로 **날짜별 그룹** 거래 리스트(같은 날짜 묶고 소계 표시).
  각 항목: 카테고리 아이콘·메모·금액(지출은 빨강 -, 수입은 초록 +).
- **📊 통계**: 이번 달 지출을 **카테고리별로 집계**해 막대/도넛(SVG, 외부 라이브러리 없이)
  으로 표시 + 순위 리스트. **월별 지출 추이**는 골프 스코어에서 쓴 SVG 라인 차트 패턴 재사용.
  예산을 설정했으면 `사용액 / 예산` 진행 바(초과 시 빨강).

FAB(+) → 거래 추가 모달: **지출/수입 토글 → 금액 → 카테고리 칩 → 날짜 → 메모**.
금액 입력은 `inputmode="numeric"`, 표시는 천단위 콤마 + `₩`.

## 통계 (요약 카드)

- 거래내역 탭: 이번 달 **수입 / 지출 / 잔액(수입-지출)**.
- 통계 탭: 카테고리별 지출 Top, 전월 대비 증감, (예산 있으면) 남은 예산·일평균 가능 지출.

## 도메인 UX 포인트

- **금액 포맷**: 항상 `Number.toLocaleString('ko-KR')` + `₩`. 지출은 음수 색(빨강),
  수입은 양수 색(초록)으로 한눈에 구분.
- **월 이동**이 핵심 내비게이션. 기본은 이번 달, `‹ ›`로 과거/미래 이동. 통계도 선택 월 기준.
- **빠른 입력** 우선: 자주 쓰는 카테고리를 앞에 두고, 최근 사용 카테고리를 기억하면 편하다.
- **내보내기**: JSON 백업(공통) + **CSV 내보내기**(엑셀에서 열도록 날짜·구분·카테고리·금액·메모 열).
- 큰 금액 입력 실수 방지를 위해 저장 전 요약(예: "지출 ₩1,200,000 · 식비") 확인은 과하지 않게.
