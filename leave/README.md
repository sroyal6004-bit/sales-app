# 직원 휴무 스케쥴 (Clinic Leave Schedule)

병원/클리닉 직원의 휴무를 **팀별로 신청·승인·관리**하고, **중요직책이 같은 날 겹쳐서 쉬지 않도록** 조정하는 모바일 웹앱(PWA)입니다. 빌드 도구 없이 단일 HTML로 동작하며 GitHub Pages 등 정적 호스팅에 바로 올릴 수 있습니다.

## 주요 기능

- **일별 / 주별 / 월별 스케쥴** — 상단 세그먼트로 전환
  - 근무자는 기본으로 표시, **휴무자는 빨간색**으로 구분
  - 월별은 달력에서 날짜별 휴무 인원(빨간 점)을 보고 탭하면 상세로 이동
- **휴무 신청 → 2단계 승인** — 직원이 날짜·종류를 신청하면 대기 상태가 되고, **팀장 1차 승인 → 행정원장 최종 승인**을 거쳐야 스케쥴에 반영됩니다. (설정에서 1단계로 전환 가능)
- **역할 기반 관리** — 관리자 모드에서 **행정원장**(최종 승인·전체 설정) 또는 **팀장**(우리 팀 1차 승인)으로 로그인. 기본 팀은 **성형팀 / 피부팀 / 데스크 / 비만**이며 설정에서 이름·팀·직급을 편집할 수 있습니다.
- **중요직책 동시 휴무 방지** — ★로 지정한 중요직책 인원이 같은 날 겹치면 승인 시 경고·차단(설정에서 허용 인원 조절 가능). 팀별 하루 최대 휴무 인원도 설정 가능.
- **설정에서 직원 명단 편집** — 팀·직책·중요직책 여부를 추가/편집/삭제.
- **관리자 모드(PIN)** — 승인과 명단·규칙 편집은 관리자 전용.
- **기기 간 동기화(선택)** — 연결 코드 + Firebase로 직원 폰과 관리자 기기가 같은 데이터를 공유.
- **오프라인 우선 · JSON 백업/복원 · 홈화면 설치(PWA)**.

## 파일

- `index.html` — 앱 전체(UI·로직·스타일)
- `manifest.json`, `sw.js` — PWA 설정 / 서비스워커(HTML 네트워크 우선 자동 업데이트)
- `icon-192.png`, `icon-512.png` — 앱 아이콘

## 사용 방법

1. 정적 호스팅(GitHub Pages 등)에 파일을 올리거나 로컬 http 서버로 엽니다.
2. 설정 → **관리자 모드**를 켜고 PIN을 정한 뒤 직원 명단을 병원 실제 인원(약 18명)에 맞게 수정합니다.
3. 중요직책 인원은 ★를 켜 둡니다.
4. 직원은 **휴무신청** 탭에서 본인을 고르고 날짜를 신청 → 관리자가 **승인** 탭에서 승인합니다.

## 기기 간 동기화 설정 (선택)

여러 사람이 같은 데이터를 보려면 Firebase 무료 프로젝트가 필요합니다.

1. console.firebase.google.com → 프로젝트 만들기
2. 빌드 → Firestore Database → 데이터베이스 만들기(테스트 모드)
3. 프로젝트 설정(⚙️) → 내 앱 → 웹(`</>`) 추가 → `apiKey` · `projectId` · `appId` 복사
4. 앱 설정 → 동기화 칸에 붙여넣고, 모든 기기에 **같은 연결 코드(10자 이상)** 입력 → 연결
5. Firestore 보안 규칙:
   ```
   match /spaces/{id} { allow read, write: if id.size() >= 10; }
   ```

동기화를 쓰지 않아도 앱은 각 기기에서 로컬로 완전히 동작합니다.
