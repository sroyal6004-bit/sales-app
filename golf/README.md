# ⛳ 골프 노트 (Golf Journal)

골프 공부한 내용과 라운드 스코어를 함께 기록하는 오프라인 PWA 앱입니다.
브라우저에서 바로 쓰고, 홈 화면에 앱으로 설치하면 오프라인에서도 동작하며,
여러 기기에서 실시간으로 함께 사용할 수 있습니다.

## 주요 기능

### 📝 학습 노트
- 카테고리별 기록 (드라이버 / 아이언 / 웨지·숏게임 / 퍼팅 / 스윙·자세 / 멘탈·루틴 / 코스공략 / 규칙·에티켓 / 체력·장비 / 기타)
- 제목·내용·태그 자유 기록, 키워드 검색 & 카테고리 필터
- **사진·동영상 첨부** (썸네일, 이미지 확대 보기, 동영상 인라인 재생)
- 학습 통계: 전체 노트 수, 이번 달 기록, 연속 기록일(스트릭)

### 📊 라운드 스코어
- 날짜·골프장·총 타수·파·퍼팅 수·메모 기록
- 파 대비(+/-) 자동 계산
- **스코어 추이 그래프** (최근 20라운드 SVG 라인 차트)
- 통계: 총 라운드, 베스트 스코어, 최근 5회 평균

### ☁️ 기기 간 동기화 (Firebase)
- 폰·데스크탑에서 같은 **연결 코드**를 입력하면 노트·스코어·사진이 실시간 동기화
- 연결 코드가 곧 비밀번호 (10자 이상, 남에게 공유 금지)
- 텍스트/스코어는 Firestore, 사진·동영상은 Firebase Storage에 저장
- 동기화 없이 오프라인 단독 사용도 가능 (기기 로컬 저장)

### 💾 백업
- 노트·스코어를 JSON 파일로 내보내기/가져오기 (사진 제외)

## 데이터 저장 구조

| 데이터 | 로컬 | 클라우드(동기화 시) |
|--------|------|---------------------|
| 노트·스코어(텍스트) | localStorage | Firestore `spaces/{연결코드}` |
| 사진·동영상 | IndexedDB | Storage `spaces/{연결코드}/{미디어ID}` |

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 앱 전체 (UI · 로직 · 스타일 단일 파일) |
| `manifest.json` | PWA 매니페스트 |
| `sw.js` | 서비스 워커 (오프라인 캐싱) |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |

## 동기화 설정 (선택)

기기 간 동기화를 쓰려면 Firebase 프로젝트가 필요합니다.
- Firestore Database 생성 + 보안 규칙 설정
- 사진·동영상 동기화까지 하려면 Firebase Storage 활성화 (Blaze 요금제 필요, 개인 사용량은 무료 범위 내)

동기화를 쓰지 않으면 각 기기에 로컬로만 저장되며, 필요 시 JSON 백업으로 데이터를 옮길 수 있습니다.
